Connection help

For live USB, open this page directly in desktop Chrome or Edge. Close Arduino Serial Monitor first, then choose Connect ESP32 and select your board’s USB port. If this preview does not support serial, open the deployed link in Chrome. The dashboard reads existing JSON at 115200 baud and does not flash or send commands to the board. Input voltage protection remains a separate hardware requirement.

You can use Import serial log with your existing output, or Try demo without a board. Demo data is simulated and is never mixed with a live session. About browser serial support ↗
